## Summary

Before the Rail-B cutover we need a parser for Vegaline Settlement's settlement files so that
Rail-B payments reconcile automatically, the same way Rail-A payments do today.

## Details

- Vegaline sends ISO 20022 `camt.054` notification files every **30 minutes** over SFTP.
- Each entry must be mapped to our ledger by **end-to-end transaction id** (not by batch
  reference, which providers can reuse).
- Duplicate entries with the same end-to-end id are dropped and logged, never double-posted.
- If no file arrives for **45 minutes** during business hours, raise a warning in #treasury-ops.

## Acceptance criteria

1. Parser handles the sample files from Vegaline's sandbox, including a partial file.
2. Reconciliation of a full day of sandbox files leaves zero exceptions.
3. Metrics: files parsed, entries matched, entries rejected, file lateness.
4. Merged and deployed to staging before the **cutover rehearsal on Thursday 15 October 2026**.

## Notes

The rehearsal and the production cutover window (Saturday 17 October, 02:00 to 04:00 SGT) are
coordinated by Treasury Ops; engineering owns parser readiness for the go/no-go call.
