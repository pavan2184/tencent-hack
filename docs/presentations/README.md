# Presentations

`internal-brain-architecture.pptx` is the architecture and trust-boundary deck for the
submission (15 slides, 16:9); slide 15 is an internal team-status slide.
`internal-brain-architecture-submission.pptx` is the version to submit: the same deck without
slide 15 (14 slides).

It is generated by `build-deck.js` (pptxgenjs). To rebuild after changing numbers or wording:

```bash
npm install pptxgenjs@3.12.0 react@18.3.1 react-dom@18.3.1 react-icons@5.3.0 sharp@0.33.5
APPLY_THEME=/path/to/pptx-skill/scripts/apply_theme.js node build-deck.js internal-brain-architecture.pptx
DECK_SUBMISSION=1 APPLY_THEME=/path/to/pptx-skill/scripts/apply_theme.js node build-deck.js internal-brain-architecture-submission.pptx
```

Run it from a scratch folder, not inside the repo, so `node_modules` stays out of git. Figures
on the slides (test counts, demo values) come from the synthetic seed corpus and the test suite
as of 13 October 2026; update them in the script when they change. Vendor comparisons on slides
10 and 11 come from `docs/ACCESS_CONTROL_INDUSTRY_REVIEW.md`; re-check them before reuse.

The visual style follows the web UI (decision D-020): white pages, near-black and grey type with
two-tone titles, one muted green accent, amber and red only for status, flat 4px cards with
hairline borders, and "01" number markers. Arial stands in for the UI's Inter Tight. Slide 9
shows real output from `main` (demo corpus, mock model). The cover in `docs/submission/` is built
by `build-cover.js` in the same style.
