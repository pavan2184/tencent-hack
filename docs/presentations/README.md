# Presentations

`internal-brain-architecture.pptx` is the architecture and trust-boundary deck for the
submission (13 slides, 16:9). Slide 13 is an internal team-status slide: delete it before
submitting.

It is generated by `build-deck.js` (pptxgenjs). To rebuild after changing numbers or wording:

```bash
npm install pptxgenjs@3.12.0 react@18.3.1 react-dom@18.3.1 react-icons@5.3.0 sharp@0.33.5
APPLY_THEME=/path/to/pptx-skill/scripts/apply_theme.js node build-deck.js internal-brain-architecture.pptx
```

Run it from a scratch folder, not inside the repo, so `node_modules` stays out of git. Figures
on the slides (test counts, demo values) come from the synthetic seed corpus and the test suite
as of 13 October 2026; update them in the script when they change.
