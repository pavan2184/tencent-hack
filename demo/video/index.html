Brain Sauce.

Permitted. Fresh. Grounded.

Tencent Cloud AI CAN DO IT Hackathon Singapore 2026 · FinTech track · Aspire case study

This is Brain Sauce.

A company's knowledge lives in Confluence, Jira, Slack, Google Drive and email.

Brain Sauce answers questions from all of it, and every answer comes with its receipts:

which documents it used, how fresh they were, and what the person asking was allowed to see.

John Tan runs finance operations and asks about next week's payment switch-over.

The answer is spread across an email, a ticket, two chat channels and a vendor list.

Brain Sauce writes it as plain sentences, and each sentence points to the document it came from.

Below the answer sits a receipt: every document it looked at, how old each one was, and how many John was allowed to read.

Every question takes the same path.

First Brain Sauce finds candidate documents.

Then it removes everything the person may not read, before any AI model sees a word.

It checks that what is left is still current, screens it for hidden instructions, lets the model write one answer,

checks every sentence against the evidence, and records the whole thing in a tamper-evident log.

Brain Sauce never copies permissions into a list of its own.

It reads each platform's own rules, Confluence restrictions, Jira security levels,

Slack channel membership, Drive sharing, and treats them as the ceiling.

An administrator does not get to read everything, and a local shortcut cannot open a document the source keeps closed.

Permissions are re-read every time a document syncs,

and for confidential files a reading older than five minutes no longer counts.

A document you cannot read looks exactly like a document that does not exist.

Mei Chen is an outside contractor and asks for the Q3 board deck figures.

The deck is confidential and not shared with Mei, so Brain Sauce declines, and nothing in the reply hints that the deck exists.

John asks the same question and gets the revenue figure, because Drive shares the deck with the leadership group.

Now the Drive owner removes that group from the share.

Nobody touches Brain Sauce.

On the next sync it reads the new permissions, John's next answer no longer uses the deck,

and the earlier answer in John's history is hidden too, because a saved answer is only as visible as the documents behind it.

Documents change.

Every indexed document carries a freshness state, and critical ones,

such as a payment runbook, are checked against the source at the moment of the question.

This failover runbook was indexed at version seven, and the source now has version eight.

So Brain Sauce marks it stale, leaves it out of the answer, and says so on the receipt.

Nothing old is passed off as current.

On our public demo, an edit to a Confluence page showed up in the next answer about sixty seconds later,

with nobody pressing sync.

An assistant that answers from company documents has to show its working.

The common fix is a second AI model that grades the first one,

which costs up to eight more calls per answer and gives a different grade every time.

We did it without a second model.

One model writes the answer under strict rules: use only the supplied documents, copy numbers, dates and names exactly,

end every sentence with a pointer to its source, and say ABSTAIN when the documents do not answer the question.

Then ordinary code, with no AI in it, checks each sentence against its source.

The same question with the same documents gives the same report, every time.

The checks are simple to explain.

Does the sentence use the words of its source?

Does the source say the opposite?

Does the sentence state a number, a date or a time the source does not contain?

Fail that last check and the sentence can never be marked supported.

If too few sentences pass, Brain Sauce abstains.

If some pass and some do not, it keeps only the supported ones and labels the answer partial.

Any document that tries to smuggle in instructions is quarantined and can never back a claim.

Everything is written to an audit log where each entry is chained to the one before, so a changed,

deleted or reordered entry shows up, and the whole log can be verified with one click.

Sam Lee works in compliance.

For John's question Sam sees who asked, which documents were considered,

which were allowed or refused and why, and the freshness receipt.

The answer text itself is hidden, because Sam cannot open the board deck.

Sam types a reason and reveals it, and that reveal becomes an entry in the same log.

Reading the log is logged.

Brain Sauce runs as one package: three small libraries for permissions, freshness and grounding,

a web app, an API, and a connector for AI agents, all in one Docker Compose file.

Answers are generated on Tencent Cloud ADP, and the demo runs entirely on the free plan.

We wrote the architecture, the data model and the API contract before the code,

so three people could build three parts in parallel and test them without any secrets or network.

That is Brain Sauce.
